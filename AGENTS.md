# AGENTS – landing-page (Next.js)

> Last updated: 2025-11-28 — Tóm tắt: Marketing website với Next.js App Router, React 19, Tailwind.

Website marketing dùng Next.js (App Router), React 19, Tailwind.

## Cấu Trúc
- `src/app/`: route theo cấu trúc thư mục.
- `src/components/`: components chia sẻ.
- Cấu hình: `next.config.ts`, `tsconfig.json`, Tailwind `postcss.config.mjs`.

## Lệnh Phát Triển / Build
- Dev: `npm run dev` (mặc định 3000).
- Build: `npm run build`.
- Chạy prod: `npm run start`.
- Lint: `npm run lint`.

## Checklist Sau Khi Code
1) `npm run lint` để đảm bảo style.
2) `npm run build` rồi `npm run start` để kiểm tra trang đã thay đổi.
3) Với thay đổi SEO/metadata, xác nhận head/meta sinh đúng.
